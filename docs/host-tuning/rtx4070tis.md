## IQ2_XS

尚未独立调参。历史量化比较或安装调用证明可以运行，不证明 CPU 布局、缓存、prefill 或采样已为该模型选优。不对外、默认不测，不新增请求。

## IQ3_XXS

2026-10-28 部署为本机唯一对外模型。当前 `config/deployments/rtx4070tis.json` 是初始基线：prefill 16384、kv-resident 20480、pool-workers 23；这些不是本机新版本上的调参结论。

优先核对八维覆盖，随后按组完成：

- CPU 辅助 0／auto：6 个实例。
- 显存预留 700／500／300：9 个实例。
- spec-min-p 0.5／0.7：6 个实例。
- prefill、kv-resident、pool-workers 和专家缓存按 16 GB 容量、sm_89、升级差异及实际告警决定补测。
- sm_86 专用解码开关表（含 `STRATA_SM86_PERF`）不在本机候选内。

每组绑定同一版本，每条件 3 个有效实例，固定其他条件；闭合后先交付结果和下一组范围，等待用户审核。当前待办和低优先级 200K／KV 对照见本机状态页。

新报告写入 `reports/rtx4070tis/<版本或主题>/`。
