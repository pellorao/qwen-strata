# 调参目标二：智力（质量）

Strata 的调参有两个目标（用户 2026-11-08）：**提高速度**（见[提速](tuning-speed.md)）和**维持或提升智力水平**（本页）。两个目标分开记录历史与进展；同一个改动对两边都有影响时，两页各记一次，只写本页目标上的影响。主机与量化各自独立，一台机器的结论不套用到另一台；细节、统计与原始证据在各报告和[调优记录](tuning.md)。

本页的约束：影响输出的参数按[测量规则](../.claude/rules/measurement.md)的分阶段判定看分数；不影响输出的参数（放置、调度、投机猜测）在本页只需证明没有把分数拉出异常。
