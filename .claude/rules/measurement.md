# 测量规则

## 设计
- 每个条件跑 3 次，取算术平均。按重要度逐个维度比较，其余条件固定；不组合成矩阵。Spec Readiness 的 medium/high × 100K/150K 是已批准的例外。
- 不同主机、不同量化的结果分开计算，不混合均值。基础条件和候选必须在同一主机内对照。
- 记录版本、全部参数、执行顺序、缓存冷暖、加载耗时；复用旧结果必须满足冻结输入、评分和固定条件完全相同。

## 计量
- token 只从引擎内部日志计算，逐个实际执行段累加 `read`（未缓存输入）、`reused`（已缓存输入）、`generated`（输出），包括续生成、压缩和 guardian 请求。用 `tools/metrics/strata_tokens.py` 计算。API usage 只用于对账。
- 缺失的计数记为未知，不填零，也不用 API 数值补。有依据时可以给出上下界范围，并说明假设。
- 每次模型运行后统计四项速度（token/s），工作时间用 `tools/metrics/review_work_time.py` 计算：
  - 引擎输入 = read / 输入处理秒数
  - 引擎输出 = generated / 解码秒数
  - 任务平均输入 = 累计 read / 工作秒数
  - 任务平均输出 = 累计 generated / 工作秒数
- 工作时间包括推理、工具执行与等待、任务内自动恢复；不包括停机，以及回合结束后等待下一条指令的空闲。
- 等效费用（美元，3 位小数，只用于用户指定的报告）=(未缓存 × 0.15 + 已缓存 × 0.016 + 输出 × 0.47) / 1e6。三类 token 任一未知，费用即未知。

## 评分口径
调参和 benchmark 用不同的评分规则，按场景选择，不混用（用户 2026-10-12）。

| | 调参（参数维度、资源校准等条件对比） | benchmark、reviewer 能力验证 |
|---|---|---|
| 目的 | 比较条件，分数只反映主要体现模型能力的因素 | 与 ARW 自己的结果直接对比 |
| 罚分 | 排除 ARW 一切"有报告诊断就整体 ×0.9"类罚分，取扣罚前分（`scoreBeforePenalty`） | 完全按 ARW 原版，罚分照算 |
| 格式错误 | 不计入分数，只记录并标在分数旁 | 计入，按 ARW 规则影响分数 |
| 可机械修复的错误 | 修复成可评分副本，只为让报告能被评分 | 修复成可评分副本，记录"做过格式修复"，再按 ARW 规则 ×0.9 |
| 无法机械修复的错误 | 按 ARW 原版判定，只影响其本身的得分项，不再整体罚分 | 按 ARW 原版处理 |

- 理由（用户 2026-10-11）：低频、随机的格式和报告诊断样本太少，不能说明能力差异，在调参中只是噪声；benchmark 需要保持 ARW 原版口径。
- 可机械修复：证据行号写成整数或裸区间对（2026-10-11）；markdown 报告第一个编号或 `- ` 条目之前的标题和说明段（2026-10-12）；正文中省略目录、能唯一对应冻结源中一个文件且行号在文件范围内的简写证据引用（2026-10-12）。只纠正写法，不改判断、finding 或证据指向；修复在绑定原实例的独立副本中进行，往返断言确认只改了这些位置，原报告不改。
- 无法机械修复：行号越界、证据写成非定位内容（如时间比较）、简写对应多个文件。
- 修复不改变样本数，每个实例无论得分高低都用同一套规则。
- 同一次测量的全部场景和实例用同一套评分规则；规则在测量中途变化时，全部跑完后按最新规则统一重评一次（不涉及模型），不逐批混用（用户 2026-10-12）。
- 平手判据（调参，用户 2026-10-11）：各条件批次得分差在 0.08 以内时，以引擎输出 tok/s 为主判据。工作时间（ARW 等场景）不确定性大，不作强选择依据。

## 失败与重跑
- 先评估错误影响范围再决定重跑：影响该场景全部重复，修复后重跑全部；只影响当前一次，只重跑这一次；不影响结果，只修复不重跑。
- 保留原始失败、恢复过程和额外消耗。不按得分挑选重跑，重跑不算作额外有效样本。

## 存放
- `.tmp/`：运行副本、完整会话、请求响应、日志、逐项裁决、进行中的进展。
- `reports/`：只放**已结束**测量的摘要（`summary.md`）和可重算的完整精度数据（`summary.json`）。不放原始明细，测量未结束不发布。
- `benchmarks/`：场景、规则、冻结输入的源文件。
- 长期文档和报告不得依赖 `.tmp/` 才能理解或重算。删除明细后无法重放的部分，要写明边界。
- 展示格式：已有表格的单位和精度不批量修改；任何舍入都不能把非零值显示成零。
