# 运行计划

开跑前按下列结构写下计划，记进该工作的进度文件（`.tmp/<工作>/`），在状态页 `now` 条目给出路径，然后直接执行。计划的作用是事先固定条件和停止点，便于开跑前核对和事后复核；目的、规模（含加测目标次数）和停止条件随结果写进报告。

1. **目的**：这组运行要回答什么问题，结论会用在哪里。
2. **模型**：量化、Strata 版本、Codex / Claude Code 版本。
3. **固定条件**：引擎参数、推理强度和预算、窗口和压缩阈值、提示文件 SHA（硬约束 3），开跑前逐项核对实际加载值。
4. **候选或维度**：比较什么，各条件取什么值。
5. **规模**：有效实例数（按测量规则定的次数；空闲加测的目标次数也在此写定）、预计请求数、模型加载次数。
6. **预计耗时**：拆成准备、运行、检查和报告几部分，写明依据（引用同类历史报告的实测值）。
7. **前置条件**：所需的安全证据、工具准备、无模型预检的状态。
8. **停止条件**：何时算完成、何时停止加测或改方向；偏离计划要记录并在汇报里说明。
