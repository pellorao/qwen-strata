# 模型运行申请

按下列结构起草申请，交给用户，然后**停下等待明确同意**。申请发出后不启动模型，也不领取 key。

1. **目的**：这组运行要回答什么问题，结论会用在哪里。
2. **主机与模型**：主机 id、量化、Strata 版本、Codex / Claude Code 版本。
3. **固定条件**：引擎参数、推理强度和预算、窗口和压缩阈值、提示文件 SHA（`config/prompts/startup-instructions.txt` 和 `config/prompts/compact-prompt.txt`）。
4. **候选或维度**：比较什么，各条件取什么值。
5. **规模**：有效实例数（每条件 3 次）、预计请求数、模型加载次数。
6. **预计耗时**：拆成准备、运行、检查和报告几部分，写明依据（引用同类历史报告的实测值）。
7. **前置条件**：所需的安全证据、工具准备、无模型预检的状态。
8. **停止点**：完成后交付什么，在哪里停下等审核。

获批后，授权覆盖到该工作项完成为止，包括故障修复和受影响的重跑。范围变化（目标、候选、维度、有效样本数）需要重新申请。
