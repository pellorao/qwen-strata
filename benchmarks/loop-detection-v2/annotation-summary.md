# 全行为标注结论

Main已完成235个现存会话及5303条模型／工具行为的循环性质核查；没有待核查会话或遗漏行为记录。确认156组循环，原有142组全部保留，新增14组。模型反复重判已定结论、以及调用方要求继续后仍无进展地返回同样结果，均作为正例保留；驱动清空后真实恢复报告、不同需求映射和真实修复仍按实际进展判断，不能仅凭新指令存在把重复豁免。

记录数和循环组数不相同：一条长思考可包含多个组，一个跨调用组也可覆盖多条记录。以上次数是已确认单位的合计；部分历史长思考穿插正常映射、比较和改写，额外细分次数不能可靠区分，仍保留下界和未知上界。全记录已核查不意味着这些次数成为精确总数，也不改变原测量报告的历史口径或性能指标。

原“有继续指令即可把相同回答判正常”的裁决已撤回。原生日志实际包含39次继续指令、37次后续可见回答，另2次没有可见回答；此前写成36次有误。加上首次回答，共38份同结果JSON；中间两次真实工具观察保留为正常边界，按6／6／26轮拆为3组，额外重复为5／5／25，共35次。两次工具检查后的首个同结果回答各作为新组首轮计入，因此37次后续回答与35次组内额外重复的口径不同；不把两个空回合计作回答。循环见证只取相同结果JSON，周边新的工具观察说明等文字不自动算循环，见[更正绑定](annotation-corrections.json)。

受控失败／取消后的回执恢复、各次新待审批命令、已完成报告被驱动清空后的重建，以及多个不同要求引用同一实现，均以实际输入变化或必要恢复支持正常标签；不以“继续”字样免责。错误工具选择、证据或审核质量问题另行保留，不直接当作循环。

完整正文采用本轮Main阅读，或复用已明确完成全部原生阅读／循环核查且原生日志SHA完全一致的旧Main证据；复用范围见[证据绑定](reused-main-reviews.json)。部分旧核查仅覆盖首次交付，其后恢复段在本轮另行核查。初始清理数据保持原字节SHA，最新真值位于[Main标注](main-annotations.json)覆盖层；不得使用压缩数据中的初始`pending-review`标签代替最新真值。

[完整性统计](annotation-validation.json)验证全部会话与行为标签的一一覆盖、原生／内容／工具结果SHA、每个循环证据的字符位置和SHA，以及原142组均有当前对应标签；问题数0。可重复检查：

```bash
python3 tools/loop/verify_model_behavior_annotations.py --out <临时JSON路径>
```

对后续工作的影响：现在可以以全集开展现有检测器的首轮离线评估，不再仅靠历史正例片段判断覆盖。跨调用旧证据窗口还须转换为连续单位、首次触发目标和正常恢复位置，才能按已确认的介入式合同计算全量F1；该适配不得向检测器提供标签或未来日志。单响应内部组仍只有完整响应可观察时的一个检测点。标签完整性通过不代表检测器通过，也不代表实时采集／送达有效。

本阶段没有更改检测判断逻辑，没有模型启动或请求，没有SSH，也没有部署文件改动。下一批阈值、匹配、重置或优先级改变仍先交用户审核；真实试跑仍须联合F1＝1、相关运行层核对及单次试跑批准。Q2_0、日常提示和两机默认配置保留，其他模型工作继续暂停。
