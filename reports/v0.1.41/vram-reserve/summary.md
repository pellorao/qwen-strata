# 本机 Q2_0 显存预留 1024 / 768 / 512

结论：三个预留值全部 27/27 正确，**引擎速度没有可测差异**（输出 122.6 / 122.8 / 123.2 token/s，相差 0.5%）。预留越少，专家缓存命中率越高（66.4% → 68.1%），但没有转化成速度；平均工作时间差异（89.4 / 90.1 / 87.2 秒）在重复间波动（标准差 1.1–3.0 秒）之内，主要随输出长度变化。按冻结的选择规则（差异在噪声内选余量大的），建议采用 **1024**，待用户选定。

适用范围：仅 本机、Q2_0、Strata v0.1.41、32K 合成短负载、桌面空闲。不能推出长上下文或 ARW 任务的收益，也测不出桌面突然增长时的溢出风险；IQ2_XS / IQ3_XXS 未调参。

## 条件

Strata v0.1.41（fb58e0d），high、思考 8192 / 输出 24576、temperature 0 / top_p 1 / top_k 20、窗口 156584、spec-min-p 0.5、23 worker / all、prefill 8192、int8 KV / resident 20480、CPU 辅助 auto、默认 profile 不保存，完整基础提示（启动 `5f9efc02…`、压缩 `3856cb62…`）。每实例冷启动、3 个请求（共享约 32K 前缀）。执行顺序 1024-1、768-1、512-1、512-2、768-2、1024-2、768-3、1024-3、512-3。引擎模板带有本机默认的会话暂存参数（8192 MiB / 4 槽 / 保留 5120 MiB），三个条件相同；计划文件中“暂存不开”的记录有误，以实际启动参数为准。

- 每 256 MiB 预留约 194 个专家槽、约 0.9 个百分点命中率；在这个负载上引擎输出速度不随之变化。
- temperature 0 下输出长度仍有变化（同条件 8315–9405 token），与上游说明一致（草稿和缓存状态可改变贪心结果）；工作时间差异主要来自输出长度，不归因于预留值。
- 运行中可用内存最低 15.2 GiB，高于 5 GiB 保留。
- 两种空闲口径不同：引擎报告的是它可用的空闲，Windows 遥测是整卡空闲，不互相换算。
