# 防循环：Strata 模型判断路线（已关闭）

**结论：放弃用 Strata 模型判断重复，只用机械规则；检测到重复后只提醒 agent 自查是否陷入无进展循环，不强制中断。**（用户 2026-10-10 决定）

依据：机械规则加 supervisor 复核，在开发集上联合 F1 为 0.6212；只用机械规则为 0.6123。模型复核的净收益可以忽略，单次判断中位 7 秒，也慢于审批延迟目标（中位约 3 秒）。只用 supervisor 的效果更差。

适用范围：rtx3080ti，Strata v0.1.41，Q2_0（部署默认参数，显存预留 512），推理强度 low，思考 512。语料为 `benchmarks/loop-detection-v2` 开发集（193 会话 / 118 组），评分按合同 v3。验证集未读取。

## 三条路线的结果

| 路线 | 做法 | 开发集结果 |
|---|---|---|
| A：只用 supervisor | 追加式会话，每一步都问是否重复 | 3 轮窗口共首次命中 9/38；调用量是 B 的 7 倍；停止 |
| B：机械先筛 + supervisor | 236 条跨记录标记全部交给模型复核 | 精确 F1 **0.6212**（tp 96.4 / fn 47.6 / fp 70，首次 82/118） |
| 只用机械规则 | 见下方轮次表 r3 | F1 **0.6123**（tp 121.3 / fn 22.7 / fp 131，首次 102/118） |
| B 的上限 | 机械 r3 + 跨记录标记全部判对 | 0.8134 |

## 主要发现

1. **一半的循环模型看不到。** 118 组中有 61 组是单条长推理内部的重复，这类记录中位约 3 万字符。模型只看裁剪后的记录时看不到这些重复；附上匹配片段后，仍会把它们判为正常推敲（概率 0–0.1）。
2. **确定性摘要无效。** 把 100 条内部标记整条交给模型，要求按顺序列出（对象，结论）条目，再由程序找重复：
   - 34 条摘要损坏：27 条用满 4096 token；2 条照抄了记录里的 `{"status":"ready"}`，把被审内容当成了指令；
   - 有效摘要里，模型会合并重复回到的条目，规则分不出真假（`target>=3` 在目标上命中 18/41，在误报上 11/23）；
   - 跑一遍要 43.5 分钟。
3. **跨记录复核的取舍不划算。** 模型剔除了 62% 的误报，但也丢掉 24% 的目标标记，其中 20 个是首次目标（权重 1）。在合同 v3 下，净效果约为零。
4. **抽样噪声大于改动效果。** 每轮约 40 条标记时，同一提示词在新旧样本上的 F1 相差约 0.1。另外，按条数外推的 F1 偏高（0.68–0.73），因为它把首次目标和后续目标同等看待；精确重放只有 0.62。
5. 分类回答比直接给概率更好用：模型只回答 `same_step` / `progress` 两个是/否问题，由程序组合结论，同一批答案可以离线换组合规则重新评分。
