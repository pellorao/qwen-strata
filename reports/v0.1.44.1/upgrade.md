# Strata v0.1.44.1 升级（rtx3080ti，IQ3_XXS）

## 结论

- rtx3080ti 已从 v0.1.43.1 升级到 Strata v0.1.44.1（提交 296b59d2），**通过短检查**（IQ3_XXS，一个实例，每项一次）。检查走实际使用的 `bin/qwen-agent` 入口，覆盖 Claude Code 2.1.299 和 Codex 0.162.0。
- 这只是短检查，不是完整验收，也不继承 v0.1.43.1 的结论。上游称默认包的回答与 0.1.43.1 逐字相同，本次没有验证逐字一致。
- 参数沿用原有 IQ3_XXS 调参结果，没有改默认值；默认档仍为 206584/150000。调参结论没有在本版上重新测量。
- 升级工具有两处缺陷，已修正并加测试（提交 4e17337）：
  - 新引擎包多了 `strata_kq.dll`，升级工具按固定清单校验，把它判为异常包而拒绝安装（没有写入任何文件）。现在允许这一个可选文件，其他多余文件仍然拒绝。
  - 维护流程出错时没有重启前端，前端停在关闭状态，已手动重启。现在无论成败都会重启前端。
- 新日志行全部能解析：14 个执行段，计量工具没有报错。
- 显存警告（#2065）照旧：C1 有 2 个请求开始时显存只剩 276 / 130 MiB，与 v0.1.43.1 相同；速度正常，没有改参数。

## 短检查（IQ3_XXS）

只有一个实例，每项跑一次，不取均值，也不算正式评分。每个阶段是一次独立的 `qwen-agent` 运行（固定 156584/100000 档，high）。C1 冷加载模型，之后的阶段复用已加载的模型。工作目录放在工程之外（`/home/pello/smoke-0.1.44.1`，已删除）。

| 阶段 | 内容 | 结果 |
|---|---|---|
| C1 | Bash 写入随机标记（经 qwen-approve 放行）→ Read 读回 → Brave MCP 搜索发布页 | 通过：标记原样读回，URL 正确，4 次审批都放行 |
| C2 | 同一会话 `/compact`（PreCompact hook 追加工程压缩提示） | 通过：24,339 → 2,252 token，压缩 33.1 秒；摘要按工程压缩提示的分节写出 |
| C3 | 同一会话恢复，不用工具回忆标记和 URL | 通过：只输出 JSON，两个值都正确，没有调用工具 |
| X1 | Codex 执行 `cat note.txt`，再用托管搜索找发布页 | 通过：命令输出正确，web_search 搜索并打开了正确的发布页 |

| 阶段 | 总耗时（秒） | 执行段 | 未缓存输入 | 已缓存输入 | 输出 | 引擎输入 token/s | 引擎输出 token/s |
|---|---:|---:|---:|---:|---:|---:|---:|
| C1（含冷加载） | 71.962 | 8 | 27918 | 59192 | 2010 | 1560.9 | 91.8 |
| C2 | 43.028 | 1 | 4626 | 20585 | 2960 | 1734.5 | 97.4 |
| C3 | 15.409 | 1 | 6975 | 13578 | 196 | 1970.3 | 102.5 |
| X1 | 33.796 | 4 | 16699 | 35249 | 989 | 1513.8 | 99.6 |
| 合计 | 164.195 | 14 | 56218 | 128604 | 6155 | 1600.6 | 96.0 |

- token 全部取自引擎日志；C1 的执行段包含 qwen-approve 的审批请求。总耗时是每个阶段 `qwen-agent` 的起止时间，C1 含冷加载。
- 速度参照：v0.1.43.1 的同类短检查合计引擎输出 95.9 tok/s，本次 96.0 tok/s。负载短、只跑一次，**不能当作版本对比**。
- X1 第一次运行时没有关闭 stdin，Codex 一直等待输入，400 秒后超时；引擎没有收到任何请求。关闭 stdin 后重跑通过。这是检查脚本的问题，不是版本问题。
- C2 的摘要用中文写成，并逐字带入了用户全局 `~/.claude/CLAUDE.md` 的约束。说明 `qwen-agent claude` 会加载用户级 Claude Code 配置；v0.1.43.1 报告里"C1 回答用了中文、原因未查"应当就是这个原因。不影响检查项。
