# 本轮profile训练的材料隔离

本轮使用本工程的10个代码/维护文档文件及4类ARW公开canonical role，构造5个独立训练请求。没有把能力fixture、隐藏预期、历史裁决或能力报告正文送入训练。实际完整提示词和清单在发送前保存，独立SHA审计已完成。第一次计量中断保留原材料；后续独立批次完成五任务，见[训练报告](profile-training.md)。

1. `MATERIALS`是明确文件清单，不递归发现文件、不读取文档引用的链接；越过指定根目录和符号链接文件被拒绝。
2. 正文源文件SHA-256与冻结验收材料107个文件哈希比较，当前没有重合。用验收expected文件的哈希冒充改名训练文件时，检查实际抛错拒绝。该检查发现整份文件复制，不能自动识别改写后的答案，因此完整输入审计仍必需。
3. 每次直接Chat请求只有一条新user消息，没有历史和工具；模型无法自行读取同机验收文件。未使用本次Codex对话作为训练上下文。
4. 已独立核对5份实际提示词SHA、10个源文件SHA，以及4类role与原版冻结清单的SHA一致；成功训练批次的证据见审计记录和材料清单。清单里给出每份完整提示词的文件名，它们也保存在同一目录。第一次中断批次的材料单独保存在`.tmp/measurement-details/v0.1.38/upgrade-cycle-20261003/profile-training-materials/`，不覆盖。
5. 学习文件使用本版本/量化专用的新路径，正常停止后保存。能力验收将逐实例重新启动并只加载冻结profile，不设置profile_save_file，不将验收结果回送训练。该验收步骤尚未执行，不能当作已验证成果。

公开审查规则允许训练与验收共用；题目、隐藏预期与裁决答案不共用。profile记录专家缓存排序，不改模型权重。这里保证的是本轮可核对的数据流；无法证明基础模型预训练时从未见过相似材料。
