# 调用方独占控制器验收

2026-10-03，Windows原生Strata v0.1.38，WSL调用方；完整使用方法位于[安装README](../../docs/installation-directory-readme.zh-CN.md#调用方使用方法)，机器可读结果见[controller.json](controller.json)。

模型服务由8101控制器独占管理，安装根目录仅公开Run-Strata-Controller.sh。领取仅在无持有者且模型停止时成功，后续启动/查询/停止/Chat/Responses验证同一key。服务端持有状态只记录key摘要，归还先生成随机新key并撤销旧key，再卸载/停止；清理失败进入blocked，未确认停止不发下一把key。停止本身保留独占权，控制器重启也不清除持有者。

## 验收结果

| 检查 | 实际结果 |
|---|---|
| Q2_0启动与基线配置 | 正确模型ready；三个量化配置SHA不变 |
| Chat与Responses | 两次真实模型短请求均正确完成，分别使用low及medium |
| 无效key | 启动、停止、归还、状态及两种推理接口403；未执行越权操作 |
| 原生8100绕过 | 无效key访问health、models、unload、settings及Chat全部403 |
| 已有持有者 | 即使模型未启动，其他领取请求也409 |
| 并发领取 | 10个真实HTTP领取请求只有1个成功，其余9个409；本地并发测试另有30个请求 |
| 控制器重启 | 只结束控制器进程后重启，原key和运行模型仍有效，新调用方领取409 |
| 运行中归还 | 撤销原key后正常关闭模型，原key再启动/停止/请求均403 |
| 归还后的控制器 | 控制器继续运行，模型无遗留进程，可领取下一把不同key |

51项本地回归通过，包含清理失败立即撤销并阻止领取、重启保留状态、损坏状态拒绝、原生维护凭据不能生成或修改settings、未知启动程序/参数拒绝、profile路径及符号链接越界拒绝、配置基线不改写。

首次重启探针使用了进程树清理，连同子模型结束，因而运行模型检查为false。该记录保留在JSON中；修正为只结束控制器后重测通过，不抹掉首次结果。安装README示例的独立运行证据另保存于[示例验收](controller-readme-example.json)。

Linux Codex也已通过provider env_key携带调用方key，实际使用本地工具读取中文UTF-8标识并完成，未使用OpenAI认证、全局配置或其他工程，见[Codex接入验收](controller-codex.json)。结束已归还key并关闭模型。

## 适用范围

这是模型API与生命周期授权验收，不是新的review评分或危险动作审批质量测量。无害短请求不证明任意业务工程质量、长上下文性能或压缩无损。未给出同一操作系统账户之间的强隔离：任意修改安装文件、读取内部维护凭据或结束宿主进程的程序属于安装维护权限范围。调用方不共享持有key、不向模型提示或版本控制暴露key，仍自行管理harness和工具沙箱。
