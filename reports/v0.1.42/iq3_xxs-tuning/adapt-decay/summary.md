# rtx3080ti IQ3_XXS 补测第 3 维：自适应层衰减（`--adapt-decay` 0.7 / 0.5 / 0.9）

结论：**保持默认 0.7**，不改部署配置。0.9 与 0.7 几乎相同（引擎输出 118.3 对 118.4 token/s）；0.5 均值 113.9，但劣势几乎全部来自一个离群实例，去掉后约 117.5（−0.8%）。缓存命中三组相同（约 70–72%），没有看到 decay 改变缓存行为。真实效应估计：0.9 约 0（±2%），0.5 为 0 到 −1.5%。27/27 全对。Main 与独立复核 agent 意见一致。

适用范围：仅 rtx3080ti、IQ3_XXS、Strata v0.1.42、32K 合成短负载；adapt-swaps 96、adapt-every 4。decay 影响长会话中换入权重的衰减，3 个请求的短负载不足以让它显出作用；真实 ARW 长会话未验证。

## 条件

同前几维：32K 合成负载、每实例 3 个请求，基础条件为已部署的胜者（不传 `--pcie-frac`、all、23 线程、`--ple-io direct`、prefill 8192、显存预留 512、spec-min-p 0.9、`STRATA_ADAPT_LAG=2`），只改 `--adapt-decay`。执行顺序：0.7-1、0.5-1、0.9-1、0.9-2、0.5-2、0.7-2、0.5-3、0.9-3、0.7-3。所有实例加载 17.3–19.4 秒，没有冷启动偏差。冻结计划：[rtx3080ti-iq3_xxs-adapt-decay-plan.json](../../../../benchmarks/resource-calibration-v1/iq3_xxs-adapt-decay-plan.json)。

## 结果（每条件 3 次算术平均）

| 条件 | 正确 | 平均工作秒 | 引擎输出 tok/s | 单次范围 |
|---|---|---|---|---|
| 0.7 | 9/9 | 107.8（±7.5） | 118.4 | 118.1–118.7 |
| 0.5 | 9/9 | 112.8（±6.8） | 113.9 | 106.8–118.5 |
| 0.9 | 9/9 | 107.2（±3.4） | 118.3 | 116.2–120.6 |

| 条件 | 引擎输入 tok/s | 任务输出 tok/s | 输出 token | 缓存命中 |
|---|---|---|---|---|
| 0.7 | 2068.4 | 99.8 | 10773 | 71.0% |
| 0.5 | 2053.6 | 96.7 | 10891 | 70.2% |
| 0.9 | 2084.9 | 99.8 | 10697 | 71.5% |

- 0.5 组第 2 个实例（全组第 5 个运行）从第 1 个请求起就慢（105.5、106.4、107.7 token/s，同组其他实例 118–124），此时自适应换入还没有累积作用；它的缓存命中正常。GPU 利用率均值 92%（其他实例 93–95%），其他进程 CPU 占用略高。判定为实例级的环境因素，不是参数效应。
- 第 5 个运行位置：上一维的离群实例 every2-r2 也在第 5 位，但形态不同（第 1 个请求正常，后两个递减）；adapt-swaps 和显存预留两维的第 5 位都正常。所以不是固定的位置效应。但排程把每维的第一个候选值固定放在第 5 位，两次离群都落在候选值上：这不改变"保持默认"的结论，但不能据此判定 0.5 或 adapt-every 2 更差，只能说它们没有显示收益。
- 资源三组相同：最低 GPU 空余约 465 MiB，最低可用内存 5.47–5.85 GiB。

## 决策记录

- Main：保持 0.7。理由是 0.9 与 0.7 持平，0.5 的劣势来自单个离群实例。
- 独立复核 agent（Opus）：保持 0.7，证据弱到中等，偏向"没有可测差异"。每条件 3 次时，单个离群实例就能移动均值约 4%，分辨力约 ±3%。建议：以后轮换排程，不固定由同一条件占第 5 位；遥测补采 GPU 温度和 SM 时钟，以排除温控降频；若真实 ARW 长会话中缓存命中逐步下降或解码明显低于约 115 token/s，用长会话负载复测 0.9。
- 结果：双方一致，不改配置。
